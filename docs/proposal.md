# MoonISO Lite 项目说明

## 项目名称

MoonISO Lite：MoonBit 原生 ISO 20022 `pain.001` 支付报文校验工具。

## 比赛方向

数据处理 / 开发者工具 / 金融报文处理。

## 真实问题

ISO 20022 正在成为跨境支付和银行间支付的重要报文标准，但 `pain.001`
报文结构复杂、字段多、格式要求严格。开发人员和测试人员经常需要手工检查
消息 ID、交易 ID、执行日期、金额、币种和控制金额，容易遗漏错误。

## 为什么有价值

- 面向银行、支付机构和金融科技公司的真实业务场景。
- 目前 MoonBit 公开包生态中缺少 ISO 20022 直接相关项目。
- 项目可以作为 MoonBit 处理金融 XML、数据校验和工程工具的能力展示。
- 验收结果清晰，适合通过 CLI 和测试自动验证。

## 当前已经完成

- MoonBit 项目骨架和 CLI
- 读取 `pain.001.xml` 文件
- 提取消息 ID、创建时间、付款指令数和交易数
- 校验必填字段
- 校验 `EndToEndId` 唯一性
- 校验日期、日期时间、金额和币种格式
- 校验 `NbOfTxs` 和实际交易数量
- 校验 `CtrlSum` 和交易金额合计
- 支持 text、JSON 和 Markdown 三种报告
- 提供有效、无效和格式错误示例
- 提供一键本地验证脚本

## 本期目标

在十月赛期内完成一个边界清晰、能够运行、能够测试的 `pain.001`
校验工具 MVP。项目不声称覆盖 ISO 20022 全部标准，而是聚焦常见的
`pain.001.001.03` 核心字段和可验证业务规则。

## 技术方案

- 主要实现语言：MoonBit
- XML 解析：MoonBit XML pull parser
- 文件读取：MoonBit 文件系统包
- 输出报告：text、JSON、Markdown
- 测试方式：`moon test` + 有效/无效/格式错误样例
- 一键验证：`scripts/check.sh`

## 验收标准

- 仓库公开，提交历史可追踪
- 使用 MoonBit 作为主要实现语言
- README 包含运行说明
- 至少包含有效和无效样例
- 单元测试全部通过
- CLI 可以成功运行并输出校验结果
- 使用 Apache-2.0 开源许可证
- 不依赖闭源服务即可完成基础校验

## 后续路线

- 增加 `pain.002`、`pacs.008`、`camt.053` 支持
- 增加 IBAN、BIC 和更多 ISO 4217 业务规则
- 增加付款指令与对账单的匹配和对账
- 增加 HTML 报告和 CI 集成
- 将校验规则抽象为可扩展规则引擎

## 开源与合规

项目使用 Apache-2.0 许可证。当前测试样例为项目自建的最小合成报文，
不包含真实客户数据，也不复制受限制的第三方实现。
